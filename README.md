# Объёмная сова-брелок

Кожевенный проект: мягкий объёмный брелок-сова ~6–7 см по высоте.
Два одинаковых корпуса (перед + зад), набивка между ними, аппликации только на переде, петля сверху под кольцо.

Исходник: фото брелока из Таиланда (аэропорт) + просьба сделать объёмную копию после истории с кладбищем в Сербии.

## Быстрый старт

1. Распечатай `patterns/layout-v2.png` 1:1 (без «вписать в страницу»).
2. Сверь толщину кожи с [docs/MATERIALS.md](docs/MATERIALS.md).
3. Режь и собирай по [docs/ASSEMBLY.md](docs/ASSEMBLY.md); нюансы стежка в [docs/STITCHING.md](docs/STITCHING.md).

Размеры по глазу с фото. Когда будут точные см и толщина кожи, правим раскройку.
