# Стежок и пробой

## Аппликации на переде (до сборки корпуса)

Порядок накладки (снизу вверх по слоям визуально):

1. Брюшко (низ)
2. Голова (верх)
3. Крылья (по бокам, чуть перекрывают голову/брюшко)
4. Глаза на голове
5. Клюв между глаз
6. Зрачки: бусины поверх глаз или кружки кожи

Стежок по аппликации: простой прямой или декоративный «через край» с шагом ~2.5–3 мм.
Глаза и клюв можно посадить на клей + 4–6 стежков, чтобы не гуляли.

Нить светло-бежевая на красном лице: так на фото-оригинале. Контрастная тёмная тоже ок, если хочешь жёстче читать шов.

## Контур корпуса (перед + зад)

1. Сложи перед и зад изнанками внутрь (лица наружу), петля сверху между ушами.
2. Пробей оба слоя вместе, начиная от одного уха, по кругу. Низ: оставь окно ~2 см без пробоя.
3. Сшей седловым стежком по пробитым отверстиям.
4. Набей. Добей пробой на окне, зашей наглухо. Узел спрячь внутрь последнего стежка.

## Натяжение

На дугах ушей тяни слабее, на прямых боках ровнее.
Если край морщит: ослабь на 1–2 стежка назад и перетяни.
