# Материалы

## Кожа

| Деталь | Цвет | Толщина | Примечание |
|--------|------|---------|------------|
| Корпус перед | красная | 1.5–2.0 мм | лицо наружу |
| Корпус зад | тёмно-коричневая | 1.5–2.0 мм | без аппликаций |
| Голова, крылья, клюв | тёмно-коричневая | 1.0–1.5 мм | тонше корпуса, легче садится |
| Брюшко, глаза | светлая / белая | 1.0–1.5 мм | контраст к красному |
| Петля | любая из корпуса | 1.5–2.0 мм | полоска 1.2×3.5 см |

Лучше растительного дубления (veg-tan) или плотный chrome для мелкой фурнитуры.
Мягкий нубук/спилок на корпус не бери: набивка выпирает и стежок плывёт.

## Нить и игла

- Вощёная нить (linen / polyester waxed), светло-бежевая, ~0.6–0.8 мм
- Две шорные иглы (harness needles) №2–4
- На пробой: вилка 3 мм или шило + линейка

## Набивка и фурнитура

- Синтепон (предпочтительно) или обрезки кожи / вата
- 2 бусины Ø6–8 мм (зрачки) или кружки тёмной кожи
- Кольцо для ключей Ø20–25 мм
- Опционально: клей для кожи (contact / PVA leather), булавки, карандаш по изнанке

## Инструмент

Ножницы по коже или сапожный нож, шило/пробойник, молоток (если вилка), наждак 400–600 или сликер для торца, линейка, бумага для шаблонов.
